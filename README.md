## Setup

To initialize, open a terminal and type:

```
npm ci
```

## Running Static Website Example

A script to run the ```basic-site``` exists in package.json.  Open a terminal and run:

```
npm run basic
```

You can also do:

```
npx serve basic-site
```

The website should then be accessible at [localhost:3000](http://localhost:3000).
